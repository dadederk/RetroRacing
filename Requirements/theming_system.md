# Theming System

## Agent summary

> Narrow tasks may stop here; open the full contract for implementation or review.

- **Scope:** Shared game themes, theme selection, asset loading, road masks, monetized theme access, and platform defaults.
- **Must not break:** Shared theme logic stays platform-agnostic; LCD remains the default free theme; watchOS keeps Pocket available by default; theme access respects Unlimited Plays where premium themes are enabled.
- **Key files:** `GameTheme`, `ThemeManager`, theme assets, `GameScene` theme application, road-mask generation scripts.

## Theme Contract

- Themes define colors, typography intent, road appearance, player/rival car styling, and SpriteKit asset references through shared types.
- `ThemeManager` owns selected theme persistence, available themes, and unlock state.
- Theme selection should use shared theme IDs rather than platform-specific branching.
- Missing theme assets must fail safely to default visuals rather than crashing gameplay.

## Current Themes

| Theme | Access | Notes |
|---|---|---|
| LCD | Free | Default RetroRapid! look. |
| Pocket | Free on watchOS; bonus/unlocked elsewhere | watchOS default remains Pocket. |
| LCD Handheld | Unlimited Plays where enabled | Premium visual variation. |
| 8-Bit | Unlimited Plays where enabled | Premium visual variation. |
| Neon/Synthwave | Unlimited Plays where enabled | Premium visual variation. |

- Unlimited Plays is the monetization entitlement. Do not introduce a separate “premium tier” in user copy.
- When adding a theme, update the catalog, assets, Settings preview/selection behavior, tests, and any App Store screenshots that rely on theme visuals.

## Platform Defaults

- Universal, tvOS, macOS, and visionOS default to LCD unless a stored user selection exists.
- watchOS defaults to Pocket for everyone.
- Platform-specific presentation can vary, but selection and access rules should remain shared.

## Assets and Road Masks

- Theme assets live in the shared asset catalog where possible.
- Road lane/lap-strip masks are generated by the Scripts workflow and must not be hand-edited.
- Verify tracked generated masks without rewriting:

```bash
swift run --package-path Scripts generate-road-dash-masks --check
```

## Accessibility

- Themes must preserve readable contrast for HUD, lane markers, cars, and overlays.
- Reduce Motion and high-contrast settings must continue to apply above theme styling.
- Big Cars and simplified road settings may alter marker rendering; see [road_markers.md](road_markers.md).

## Testing

- Unit tests cover theme catalog availability, default selection, persistence, unlock behavior, platform defaults, and missing-asset fallback.
- Visual/manual checks cover Settings preview, gameplay readability, road mask rendering, light/dark appearance, and screenshot-capture fixtures.
