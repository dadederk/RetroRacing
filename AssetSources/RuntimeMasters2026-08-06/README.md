# Runtime Masters 2026-08-06

Canonical source provenance for the shared 64-Bit SpriteKit family.

- `Generated/64Bit/` preserves the original flat-green ImageGen outputs for the
  superseded rival concept, player helmet, friend helmet, and crash.
- `TransparentMasters/64Bit/` preserves their soft-matte cutouts plus the
  deterministic visionOS player render. The superseded hue-shifted rival is
  retained as `rivalsCar-64Bit-master-v1.png` for review provenance.
- `CuratedVisionOS/` contains the fixed-camera rival projection rendered by the
  spatial production workflow from the dedicated rival USDA composition.
- `CuratedCatalog/Sprites/64Bit/` contains per-platform inputs normalized to
  the established canvas sizes, alpha bounds, and bounded runtime palettes.
- `PROMPTS.md` records the built-in ImageGen prompt set, including the
  superseded rival concept, and the normalization contract for assets that
  remain ImageGen-derived.

This directory is source provenance only. It must never be added to an Xcode
target or copied into a Release product.
