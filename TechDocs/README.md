# TechDocs

Durable technical explainers for how larger systems in RetroRapid! fit together.

Use `TechDocs/` for plain-English architecture notes, flow diagrams, and onboarding context. Keep shipped behavior contracts in `Requirements/`; a TechDoc can explain the system, but the requirement file remains the source of truth for what must ship.
