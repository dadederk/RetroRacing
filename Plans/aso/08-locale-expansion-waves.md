## Completed wave (2026-07-23)

1. German (`de-DE` / in-app `de`)
2. Dutch (`nl-NL` / in-app `nl`)
3. Italian (`it`)
4. French (`fr-FR` / in-app `fr`)

Delivered as one package: String Catalog, App Store metadata, screenshot captions, TestFlight notes, and ASC 1.5 draft localizations.

## Completed wave (2026-07-25)

1. Japanese (`ja`)
2. Korean (`ko`)
3. Brazilian Portuguese (`pt-BR`)
4. Traditional Chinese (`zh-Hant`)

Delivered as one package folded into the 1.5 draft: String Catalog, App Store metadata, screenshot captions, IAP/Game Center localizations, TestFlight notes, and ASC version localizations.
